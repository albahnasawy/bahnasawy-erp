# نظام البهنساوي المحاسبي وإدارة المخازن (أدوات صحية وسباكة)

نظام سطح مكتب متكامل يعمل أوفلاين بالكامل (Off-line First) على نظام Windows بقاعدة بيانات SQLite محلية، ومصمم خصيصاً لمتجر **البهنساوي للأدوات الصحية والسباكة** (إدارة: إبراهيم البهنساوي — `01020494954`).

---

## 🌐 رابط معاينة الويب التفاعلية على أي متصفح
جرّب البرنامج كاملاً مباشرة من المتصفح (حفظ تلقائي داخل المتصفح لتجربة كل الشاشات والصلاحيات والطباعة):
🔗 **https://albahnasawy.github.io/bahnasawy-erp/**

---

## بيانات الدخول الافتراضية
| الدور | اسم المستخدم | كلمة المرور | الصلاحيات |
|---|---|---|---|
| المدير العام | `admin` | `admin123` | كامل الصلاحيات + صافي الأرباح + إلغاء/حذف الفواتير + الإعدادات والنسخ الاحتياطي |
| كاشير | `cashier` | `1234` | نقطة البيع والعملاء والمرتجعات والاطلاع على المخزون بدون تكلفة الشراء أو الأرباح أو الحذف |
| أمين مخزن | `warehouse` | `1234` | الأصناف والباركود والمخازن والتحويلات والمشتريات والموردين والشيكات |

> **مهم:** يُنصح بتغيير كلمات المرور الافتراضية من قائمة **الإعدادات والنسخ الاحتياطي ← المستخدمون والصلاحيات** فور البدء.

## التشغيل المحلي لسطح المكتب على Windows (بقاعدة SQLite الفعلية)
1. ثبّت الحزم (لأول مرة):
   ```bash
   npm install
   npm run build
   ```
2. اضغط مزدوجاً على الملف: **`تشغيل-برنامج-البهنساوي.bat`**
   أو شغّله من سطر الأوامر:
   ```bash
   npm start
   ```
   ثم افتح الرابط: `http://127.0.0.1:4850`

## المميزات الرئيسية المطبقة طبقاً لمتطلبات المتجر
- **تعدد وحدات القياس والتحويل التلقائي:** قطعة / دستة / كرتونة، متر / لفة / عود، و**الأطقم المجمعة (Kits)** التي تخصم وتسترد مكوناتها تلقائياً من المخزن.
- **تصنيف كامل وباركود:** تصنيف حسب المقاس (بوصة/مم)، الماركة، اللون، دعم قارئ الباركود، واستوديو طباعة ملصقات الباركود (ملصقات حرارية `50×25mm` أو ورق لاصق `A4`).
- **مخازن متعددة وتحويلات وجرد:** مخزن رئيسي + مخزن فرعي + تنبيهات الحد الأدنى + سجل حركات كامل.
- **المبيعات والسباكين:** 3 مستويات تسعير (`قطاعي` / `سباك` / `جملة ومقاولين`)، ربط فاتورة العميل باسم السباك للتقارير فقط، بيع آجل وأقساط، ومرتجع جزئي بعد التشطيب **بسعر الفاتورة القديمة تلقائياً**.
- **المشتريات وتكلفة الشحن والتوالف:** توزيع مصاريف الشحن والنقل نسبياً على تكلفة الأصناف وتحديث آخر سعر شراء، ومرتجع مشتريات للتوالف، وحسابات الموردين والشيكات وتواريخ استحقاقها.
- **الخزائن والضرائب والتقارير:** خزنة كاشير يومية + خزنة رئيسية + إنستاباي/بنك + محافظ إلكترونية + مصروفات يومية + تفعيل/تعطيل ضريبة القيمة المضافة (`14%`) + تقارير صافي الأرباح اليومية والشهرية والنواقص والأكثر مبيعاً والراكد.
- **الطباعة والنسخ الاحتياطي:** طباعة فواتير `80mm` حرارية و`A4` و`A5`، ونسخ احتياطي يومي تلقائي على الجهاز مع دعم النسخ إلى فلاشة USB واستعادة قاعدة البيانات `.db`.
